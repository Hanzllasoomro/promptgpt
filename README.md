# Design Brain

A standalone React and Express app for turning rough ideas into structured prompts.

## Run locally

```powershell
npm install
npm run dev
```

Open http://localhost:5000.

The app uses in-memory storage and a deterministic local prompt generator, so no database, API key, or hosted platform account is required. Saved prompts reset when the server restarts.

## Other commands

```powershell
npm run dev:client
npm run check
npm run build
npm start
```
